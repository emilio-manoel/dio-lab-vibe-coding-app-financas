# 💰 FinanceFlow

## 📌 Sobre o Projeto

O **FinanceFlow** é uma aplicação web para gerenciamento financeiro desenvolvida durante a trilha de **React** da **Digital Innovation One (DIO)**.

Este projeto representa a evolução de uma ideia criada anteriormente durante o desafio de **Vibe Coding**, no qual foi elaborado um conceito de aplicação financeira utilizando Inteligência Artificial e engenharia de prompts. Em vez de iniciar um novo projeto do zero, decidi transformar aquele conceito em uma aplicação funcional, implementando toda a interface e a lógica utilizando tecnologias modernas do ecossistema React.

O objetivo foi aplicar na prática os conhecimentos adquiridos ao longo da formação, criando uma aplicação mais próxima das utilizadas no mercado e consolidando conceitos importantes do desenvolvimento Front-End.

---

# 🚀 Tecnologias Utilizadas

## ⚛️ React

A interface da aplicação foi desenvolvida utilizando **React**, permitindo dividir o sistema em componentes reutilizáveis, facilitando a manutenção do código e tornando o projeto mais organizado e escalável.

---

## ⚡ Vite

O projeto utiliza **Vite** como ferramenta de desenvolvimento, proporcionando uma experiência rápida durante a programação, compilação otimizada e atualização instantânea da aplicação.

---

## 🔷 TypeScript

Toda a aplicação foi desenvolvida com **TypeScript**, aumentando a segurança através da tipagem estática, reduzindo erros e tornando o código mais legível e fácil de manter.

---

## 📊 Gerenciamento de Estado

A aplicação utiliza gerenciamento de estado para controlar as informações financeiras e manter os componentes sincronizados durante toda a utilização do sistema.

Essa abordagem facilita a atualização dinâmica da interface e melhora a organização da aplicação.

---

## 🎨 CSS

A estilização foi desenvolvida com foco em uma interface moderna, limpa e responsiva, proporcionando uma boa experiência para usuários em diferentes dispositivos.

---

# 💼 Funcionalidades

O FinanceFlow foi desenvolvido para oferecer uma experiência simples e intuitiva no gerenciamento financeiro.

Entre suas principais funcionalidades estão:

* cadastro e organização de informações financeiras;
* visualização clara dos dados;
* interface responsiva;
* componentes reutilizáveis;
* atualização dinâmica da interface;
* estrutura preparada para futuras funcionalidades.

---

# 📈 Evolução do Projeto

O FinanceFlow surgiu a partir de uma ideia desenvolvida durante um desafio de **Vibe Coding** da DIO.

Na primeira versão, o objetivo era aprender a utilizar Inteligência Artificial para criar um conceito de aplicação através de prompts e documentos de requisitos (PRD).

Posteriormente, durante a trilha de React, decidi transformar esse conceito em um projeto real, desenvolvendo a aplicação utilizando React, TypeScript e outras tecnologias modernas.

Essa evolução permitiu colocar em prática conhecimentos adquiridos durante os estudos e demonstrou como uma ideia inicialmente criada com apoio da IA pode se transformar em uma aplicação desenvolvida manualmente, utilizando boas práticas de desenvolvimento.
