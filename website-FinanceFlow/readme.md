# 💼 FinanceFlow - Website

## 📌 Sobre o Projeto

O **FinanceFlow** é um website desenvolvido com o objetivo de apresentar uma solução moderna para gestão financeira de forma clara e intuitiva. O projeto foi criado para praticar a construção de interfaces responsivas, organização de componentes e boas práticas de desenvolvimento front-end.

A página possui um layout moderno, destacando os principais recursos da plataforma, seus benefícios e uma experiência visual agradável para diferentes dispositivos.

Além de servir como um exercício prático de desenvolvimento, o projeto demonstra a importância de criar interfaces que valorizem tanto a experiência do usuário quanto a organização do código.

---

# 🚀 Tecnologias Utilizadas

## ⚛️ React

A interface foi construída utilizando **React**, permitindo desenvolver componentes reutilizáveis e facilitar a manutenção da aplicação.

Essa abordagem torna o projeto mais organizado, escalável e preparado para futuras evoluções.

---

## ⚡ Vite

O projeto utiliza **Vite** como ferramenta de desenvolvimento, proporcionando inicialização rápida, atualização instantânea durante a programação e um processo de build otimizado.

---

## 🔷 TypeScript

O código foi desenvolvido utilizando **TypeScript**, adicionando tipagem estática ao projeto.

Essa tecnologia aumenta a confiabilidade da aplicação, facilita a identificação de erros durante o desenvolvimento e melhora a legibilidade do código.

---

## 🎨 CSS

Toda a estilização da interface foi desenvolvida com CSS, criando um layout moderno, organizado e responsivo.

Foram aplicadas boas práticas de organização visual para proporcionar uma navegação agradável em diferentes tamanhos de tela.

---
